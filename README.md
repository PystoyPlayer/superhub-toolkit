# Superhub Toolkit для Safari

[Скачать текущую сборку](https://github.com/PystoyPlayer/superhub-toolkit-safari/releases/latest)

Распакуйте архив и следуйте инструкции внутри. Для работы функций расширения нужен доступ к сервисам Superhub.

Репозиторий содержит выпуски Safari и инструкции по установке.
