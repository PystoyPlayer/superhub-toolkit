# Superhub Toolkit для Safari и Chrome

[Скачать для Safari](https://github.com/PystoyPlayer/superhub-toolkit/releases/latest) · [Скачать для Chrome](https://github.com/PystoyPlayer/superhub-toolkit/releases/tag/chrome-v26.8.30) · [Superhub Wiki](https://wiki.superhub.team/doc/ispolzovanie-Fo1ol7rtzW)

Расширение для поддержки Superhub в Chatwoot. Требуется Safari 18.4+ на Mac с Apple Silicon или Intel либо Chrome 114+.

## Установка

**Safari.** Распакуйте ZIP, перенесите **Superhub Toolkit.app** в «Программы» и запустите. Включите Toolkit в **Настройки → Расширения** и разрешите доступ к `chat.superhub.team`, `service.superhub.team` и `support.superhub.team`. Если сайта нет в списке, откройте его и выберите **«Всегда разрешать на этом веб-сайте»** через значок Toolkit.

**Chrome.** Распакуйте ZIP. На странице `chrome://extensions` включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.

В настройках Toolkit войдите с рабочим аккаунтом портала и обновите Chatwoot. После полного выхода из Chrome нужно войти в Toolkit снова.

## Возможности

- **Услуги.** Нажмите ID или UUID в чате, чтобы открыть карточку и скопировать ссылки для Mattermost. На вкладке «Услуги» можно найти сервер из диалога, рассчитать перенос или докупку ресурсов.
- **Заявки Jira.** Toolkit подставляет ссылку на диалог в форму заявки. Заметку из портала можно скопировать, вставить в черновик или отправить клиенту.
- **Вкладки Chatwoot.** «Заявки», «Тарифы» и «Ноды» следуют теме чата. Ноды сортируются по загрузке внутри каждой группы.
- **Работа с сообщениями.** Готовый ответ из отчёта агента и черновик бота можно скопировать с форматированием. Toolkit отмечает незнакомые домены и скрывает подсказку «Назначить мне».

## Действия после отправки шаблонов

| Ответ клиенту | Действие |
| --- | --- |
| `/закрыть-1`, `/готово` или шаблон о передаче заявки администрации | Откладывает диалог до следующего ответа клиента |
| Шаблон о передаче заявки второй линии | Назначает команду `support l2` |

## Обновление

Ссылка на новую версию появляется в настройках Toolkit. В Safari замените приложение в «Программах». В Chrome замените файлы в папке расширения и нажмите **Обновить** на странице `chrome://extensions`. Затем обновите Chatwoot.
