# Superhub Toolkit для Safari и Chrome

[Скачать для Safari](https://github.com/PystoyPlayer/superhub-toolkit/releases/latest) · [Скачать для Chrome](https://github.com/PystoyPlayer/superhub-toolkit/releases/tag/chrome-v26.8.30) · [Инструкция Superhub Wiki](https://wiki.superhub.team/doc/ispolzovanie-Fo1ol7rtzW)

Superhub Toolkit — внутренний инструмент для сотрудников. Для Safari нужен Mac с Apple Silicon или Intel и Safari 18.4 или новее. Для Chrome нужен браузер версии 114 или новее.

## Установка в Safari

1. В разделе **Assets** последнего релиза скачайте `Superhub-Toolkit-Safari-…zip`. Распакуйте архив, перенесите **Superhub Toolkit.app** в «Программы» и запустите.
2. В Safari откройте **Настройки → Расширения** и включите **Superhub Toolkit**. С версии 26.8.26 сборка подписана Developer ID и нотарифицирована Apple.
3. Выберите Toolkit, откройте **«Изменить веб-сайты…»** и разрешите доступ к `chat.superhub.team`, `service.superhub.team` и `support.superhub.team`. Если нужного сайта нет в списке, откройте его и нажмите значок Toolkit в панели Safari. Выберите **«Всегда разрешать на этом веб-сайте»**.
4. В настройках Toolkit войдите с аккаунтом портала Superhub и обновите Chatwoot сочетанием **⌘R**.

Если «Заявки», «Тарифы» или «Ноды» остаются светлыми в тёмном Chatwoot, откройте сайт по ссылке в подсказке, разрешите Toolkit доступ и обновите Chatwoot.

## Установка в Chrome

1. Скачайте архив `Superhub-Toolkit-Chrome-…zip` из релиза Chrome и распакуйте в папку, где она будет храниться.
2. Откройте `chrome://extensions` и включите **Режим разработчика**. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
3. Откройте настройки Toolkit через значок на панели Chrome и войдите в рабочий аккаунт портала. Обновите Chatwoot. После полного выхода из Chrome войдите в Toolkit снова.

При выходе новой версии скачайте Chrome ZIP, замените файлы в той же папке и нажмите **Обновить** на карточке Toolkit в `chrome://extensions`. Ссылка на доступную версию появится в настройках расширения.

Если установлен Chrome Toolkit 26.8.27, скачайте текущую версию вручную по ссылке вверху. В актуальной сборке проверка обновлений использует новый адрес репозитория.

## Возможности

- **Карточка услуги в чате.** Нажмите ID или UUID в сообщении, чтобы посмотреть статус, тариф, лимиты, а также быстро скопировать ссылки на Retool и Pterodactyl.
- **Вкладка «Услуги».** Показывает карточки услуг из истории диалога без дублей. Есть поиск по ID и UUID.
- **Серверы из диалога.** Список с поиском по названию, ID или UUID. Выберите сервер, чтобы открыть расчёт, или раскройте детали в списке.
- **Расчёт переноса.** Сравнивает тарифы при смене линейки или конфигурации. Показывает характеристики и подбирает вариант с нужными ресурсами.
- **Ноды.** Карточки отсортированы по возрастанию загрузки внутри каждой линейки и группы доступности.
- **Докупка ресурсов.** Считает доплату по каталогу за ЦПУ, ОЗУ и диск, в том числе для вечных серверов. Прибавку можно учесть при расчёте переноса.
- **Тема Chatwoot.** «Заявки», «Тарифы» и «Ноды» следуют теме чата. Для тёмной темы «Тарифов» и «Нод», а также сортировки нод нужен доступ к `support.superhub.team`.
- **Заявки.** Toolkit подставляет ссылку на текущий диалог в пустое поле формы заявки.
- **Внутренние отчёты.** Toolkit выделяет разделы отчёта агента и готовый ответ клиенту. Готовый ответ и черновик бота можно скопировать отдельно, сохранив форматирование.
- **Поле ответа.** Toolkit скрывает подсказку «Назначить мне». После отправки `/закрыть-1` или «Готово. Проверьте, пожалуйста. Наша помощь ещё требуется?» диалог откладывается до следующего ответа клиента. После отправки шаблона о передаче заявки администрации диалог также откладывается, а после отправки шаблона второй линии Toolkit назначает команду `support l2`.
- **Приватные заметки портала.** Распознанную заметку можно скопировать, перенести в черновик или отправить клиенту.
- **Внешние ссылки.** Toolkit помечает незнакомые домены в сообщениях клиентов.
- **Статистика.** В настройках видны число открытых карточек за сегодня и время первой и последней активности.

## Обновление Safari

Toolkit проверяет новые релизы при открытии Chatwoot или настроек расширения. Если появилась новая версия, ссылка **«Скачать Safari …»** появится рядом с номером версии внизу экрана настроек.

Скачайте ZIP, распакуйте его и замените **Superhub Toolkit.app** в «Программах». Затем обновите вкладку Chatwoot сочетанием **⌘R**.
