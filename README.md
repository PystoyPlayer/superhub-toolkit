# Superhub Toolkit

Расширение для поддержки Superhub в Chatwoot. Добавляет карточки серверов, расчёт стоимости и инструменты для работы с заявками Jira.

| Браузер | Сборка |
| --- | --- |
| Safari 18.4+ на Mac с Apple Silicon или Intel | [Скачать для Safari](https://github.com/PystoyPlayer/superhub-toolkit/releases/latest) |
| Chrome 114+ | [Скачать для Chrome](https://github.com/PystoyPlayer/superhub-toolkit/releases/tag/chrome-v26.8.30) |

[Инструкция в Superhub Wiki](https://wiki.superhub.team/doc/ispolzovanie-Fo1ol7rtzW)

## Установка

### Safari

1. Распакуйте ZIP, перенесите **Superhub Toolkit.app** в «Программы» и запустите.
2. В **Safari → Настройки → Расширения** включите **Superhub Toolkit**.
3. В **«Изменить веб-сайты…»** разрешите доступ к `chat.superhub.team` для диалогов, `service.superhub.team` для заявок и `support.superhub.team` для тарифов и нод. Если сайта нет в списке, откройте его и выберите **«Всегда разрешать на этом веб-сайте»** через значок Toolkit.

<summary>Как разрешить неподписанную сборку в Safari</summary>

Сборка Safari из актуального релиза на GitHub подписана и нотарифицирована Apple. Для установки неподписанной сборки выполните два шага.

1. В **Safari → Настройки → Дополнения** включите показ функций для веб-разработчиков.
2. В разделе **Разработчик** включите **«Разрешить неподписанные расширения»** (*Allow unsigned extensions*). После полного выхода из Safari эту настройку нужно включить снова. [Инструкция Apple](https://developer.apple.com/documentation/safariservices/running-your-safari-web-extension)

</details>

### Chrome

1. Распакуйте ZIP в папку, где будет храниться расширение.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.

### Вход

Откройте настройки Toolkit через значок расширения, войдите с рабочим аккаунтом портала Superhub и обновите вкладку Chatwoot. После полного выхода из Chrome нужно войти в Toolkit снова.

## Работа в Chatwoot

- **Серверы и цены.** Нажмите ID или UUID в сообщении, чтобы открыть карточку сервера и скопировать ссылки для Mattermost. На вкладке «Услуги» найдите сервер из диалога и рассчитайте стоимость переноса или докупки ресурсов.
- **Заявки.** Toolkit заполняет пустое поле ссылки на диалог в форме Jira. Приватную заметку из портала можно скопировать, вставить в черновик или отправить клиенту.
- **Тарифы и ноды.** Вкладки «Заявки», «Тарифы» и «Ноды» следуют теме Chatwoot. Ноды сортируются по возрастанию загрузки внутри каждой группы.
- **Сообщения.** Готовый ответ из отчёта агента и черновик бота можно скопировать с форматированием. Toolkit отмечает незнакомые домены в ссылках и скрывает подсказку «Назначить мне».

### Действия после отправки шаблонов

| Ответ клиенту | Действие |
| --- | --- |
| `/закрыть-1` или `/готово` | Откладывает диалог до следующего ответа клиента |
| Шаблон о передаче заявки администрации | Откладывает диалог до следующего ответа клиента |
| Шаблон о передаче заявки второй линии | Назначает команду `support l2` |

## Обновление

Ссылка на новую версию появляется в настройках Toolkit.

- **Safari.** Распакуйте новый ZIP и замените приложение в «Программах».
- **Chrome.** Замените файлы в папке расширения и нажмите **Обновить** на странице `chrome://extensions`.

Обновите вкладку Chatwoot после установки новой версии.
