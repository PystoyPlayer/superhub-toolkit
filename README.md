# Superhub Toolkit для Safari

[Скачать последнюю сборку](https://github.com/PystoyPlayer/superhub-toolkit-safari/releases/latest) · [Инструкция Superhub Wiki](https://wiki.superhub.team/doc/ispolzovanie-Fo1ol7rtzW)

Superhub Toolkit — внутренний инструмент для сотрудников. Сборка подходит для Mac с Apple Silicon и Intel и требует Safari 18.4 или новее.

## Установка

1. В разделе **Assets** последнего релиза скачайте `Superhub-Toolkit-Safari-…zip`. Распакуйте архив, перенесите **Superhub Toolkit.app** в «Программы» и запустите.
2. В Safari откройте **Настройки → Расширения** и включите **Superhub Toolkit**. С версии 26.8.26 сборка подписана Developer ID и нотарифицирована Apple.
3. Выберите Toolkit, откройте **«Изменить веб-сайты…»** и разрешите доступ к `chat.superhub.team` и `service.superhub.team`. Если нужного сайта нет в списке, откройте его и нажмите значок Toolkit в панели Safari. Выберите **«Всегда разрешать на этом веб-сайте»**.
4. В настройках Toolkit войдите с аккаунтом портала Superhub и обновите Chatwoot сочетанием **⌘R**.

Если «Заявки» остаются светлыми, откройте портал по ссылке в подсказке, разрешите Toolkit доступ к `service.superhub.team` и обновите Chatwoot.

## Возможности

- **Карточка услуги в чате.** Нажмите ID или UUID в сообщении, чтобы посмотреть статус, тариф, лимиты, а также быстро скопировать ссылки на Retool и Pterodactyl.
- **Вкладка «Услуги».** Показывает карточки услуг из истории диалога без дублей. Есть поиск по ID и UUID.
- **Серверы из диалога.** Список с поиском по названию, ID или UUID. Выберите сервер, чтобы открыть расчёт, или раскройте детали в списке.
- **Расчёт переноса.** Сравнивает тарифы при смене линейки или конфигурации. Показывает характеристики и подбирает вариант с нужными ресурсами.
- **Ноды.** Карточки отсортированы по возрастанию загрузки внутри каждой линейки и группы доступности.
- **Докупка ресурсов.** Считает доплату по каталогу за ЦПУ, ОЗУ и диск, в том числе для вечных серверов. Прибавку можно учесть при расчёте переноса.
- **Тема Chatwoot.** «Заявки», «Тарифы» и «Ноды» следуют теме чата. Для оформления списков и карточек внутри «Тарифов» и «Нод» можно разрешить Toolkit доступ к `support.superhub.team` в настройках Safari.
- **Заявки.** Toolkit подставляет ссылку на текущий диалог в пустое поле формы заявки.
- **Внутренние отчёты.** Toolkit выделяет разделы отчёта агента и готовый ответ клиенту. Готовый ответ и черновик бота можно скопировать отдельно, сохранив форматирование.
- **Поле ответа.** Toolkit скрывает подсказку «Назначить мне». После отправки шаблона `/закрыть-1` диалог откладывается до следующего ответа клиента.
- **Приватные заметки портала.** Распознанную заметку можно скопировать, перенести в черновик или отправить клиенту.
- **Внешние ссылки.** Toolkit помечает незнакомые домены в сообщениях клиентов.
- **Статистика.** В настройках видны число открытых карточек за сегодня и время первой и последней активности.

## Обновление

Toolkit проверяет новые релизы при открытии Chatwoot или настроек расширения. Если появилась новая версия, ссылка **«Скачать Safari …»** появится рядом с номером версии внизу экрана настроек.

Скачайте ZIP, распакуйте его и замените **Superhub Toolkit.app** в «Программах». Затем обновите вкладку Chatwoot сочетанием **⌘R**.
